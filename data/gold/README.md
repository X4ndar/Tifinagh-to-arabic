Nothing here was produced by the converter. Wikidata files are CC0 and can be
rebuilt with `npm run gold:build` (network required). See
`docs/evaluation.md` for how each set is used and `NOTICE.md` for licensing.

To add verified data, create a new JSON file with `entries` of the form
`{ "tifinagh": "…", "arabic": "…", "source": "…" }`, name the source (person,
publication or dataset with license), and add it to
`benchmarks/evaluate.mjs`. Do not add spellings generated by this converter.
